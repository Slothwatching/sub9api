05 / 防翻车

    
想让 AI 多干点？先躲开这 6 个坑

    
用 AI 写论文，最常见的问题不是“被查出来”，而是出现低级、明显的错误。

    

      
👻
编造的参考文献
普通聊天最容易编造 DOI。所以要在 AGENTS.md 里规定：只收录有真实 DOI 的文献，查不到就标注“未验证”。答辩时导师随手一查就能发现。

      
🪞
只挑对自己有利的文献
只引用“支持”你观点的文献，综述就会写成一边倒。看板里的“反驳”数，就是你写“研究争议”部分的现成素材。

      
🔒
违规上传全文
学校订阅了某篇文章，不代表你可以把全文喂给 AI。看清“GenAI 使用权”，不可用的就自己读。

      
📜
不了解学校规定
各校、各专业对 AI 写作的要求差别很大。动手前先查规定、问导师，按要求披露 AI 的使用情况。

      
🎤
答辩时讲不出来
AI 起草的段落如果你没读懂原文，答辩被追问一句就答不上来。看板上每篇文献至少要读摘要和结论。

      
🌀
AI 越权操作
不加限制的话，智能体会自己去搜网页、改文件。每条提示词都要写清楚边界，比如“不要修改文件”“完成后停止”。

Codex 操作速查卡

  • New chat：在当前项目下开一个新对话，能看到同一个文件夹
    • 
        
  • Project → Local：绑定电脑上的文件夹（新手先用这个）
    • 
        
  • Plugins：安装、授权文献插件（如 scite、Article Galaxy）
    • 
        
  • Side chat：开一个不打断主任务的侧边对话，用来问“这段代码是什么意思”
    • 
        
  • Browser：内置浏览器，直接预览生成的网页
    • 
        
  • Annotate：在网页上圈出要改的地方并写意见，一次性发给 Codex
    • 
        
  • Terminal / Files：查看 Codex 运行的命令和项目文件
    • 
        
  • Pin：多个对话同时运行时，把对话置顶
    • 
      

      
✍️ 提示词黄金法则
    
        
  • 用 @ 点名插件：写 @scite，不要只写“查文献”
    • 
        
  • 先计划后动手：“什么都别改，先写一份计划给我看”
    • 
        
  • 每步都设边界：“不要修改文件”“只用 X”“完成后停止”
    • 
        
  • 限定数量：“不超过 5 篇”，每步能控制在 2–5 分钟内完成
    • 
        
  • 让它自己检查：“运行校验脚本并报告结果”
    • 
        
  • 界面可以随意改：给它一张截图或一个参考网站，说“照这个风格改”
    • 
      

      
💰 省 token（省钱）
    
        
  • 结果一定要存进 review.json，之后只读文件，不用重复检索
    • 
        
  • 读取、展示类任务可以切换到更便宜的模型
    • 
        
  • 少用网页搜索：网页内容又贵又不一定准确
    • 
        
  • 一个子问题一轮，不要一次让它“把整个领域全查一遍”
    • 
      

      
🧠 名词解释
    
        
  • MCP / 插件：让 Codex 能直接调用外部数据库的接口
    • 
        
  • AGENTS.md：项目规则文件，Codex 每次回答前都会读
    • 
        
  • JSON：结构化数据格式，AI 读得又快又准
    • 
        
  • 支持 / 反驳 / 提及：别的论文引用这篇时的态度
    • 
        
  • GenAI 使用权：能否合规地把全文交给 AI 阅读

Codex 和普通 ChatGPT 聊天有什么区别？
聊天只能一问一答，文件要手动上传。Codex 直接在你电脑的文件夹里工作：自己读写文件、写代码、运行代码、检查结果，一个任务能自动连续跑完很多步，而且可以反复运行。

      
我完全不会编程，能用吗？
能。代码都是 Codex 写的，你只要用中文说清楚“想要什么、不许做什么”。看不懂的地方，开一个 Side chat 让它解释。

      
一定要装 scite 和 Article Galaxy 吗？
不是必须的，但强烈推荐。没有文献插件的话，Codex 只能凭记忆或网页搜索，编造引用的风险会高很多。scite 有免费试用；如果学校买了机构版，可以先问图书馆。

      
每一步要等多久？
一般 2–5 分钟。第一次检索文献最慢，因为 Codex 会多次调整检索式。等待时可以开一个新对话做别的事（比如第 9 关）。

      
能直接让它把整篇论文写出来吗？
技术上可以生成文字，但这样风险最大：编造引用、观点一边倒、答辩讲不出来，还可能违反学校规定。更稳妥的做法是第 12 关（加分关）：让它基于你核实过的证据生成提纲和草稿，每句话都标注 DOI，然后由你改写定稿。

      
换一章、换一个问题，要从头再来吗？
不用。做完第 11 关后，项目里会有模板和说明文档。之后只要说“按 README 为这个新问题生成一个证据看板”，Codex 就会把整套流程再跑一遍。
