# 每次复用的审阅检查清单

## 项目与研究范围

- [ ] 在独立研究副本工作，保留已有 `data/review.json`；不以空模板覆盖旧研究。
- [ ] 阅读并遵守 `AGENTS.md`；更新副本的研究用途，保留禁止采购与不编造规则。
- [ ] 明确研究问题的人群、干预、对照、主要结局、研究类型及筛选范围。
- [ ] 填入本次实际研究问题与审阅日期，日期采用 `YYYY-MM-DD`。

## 文献发现与人工核对

- [ ] 优先使用 @scite；不可用时明确记录替代检索服务、检索范围及证据来源。
- [ ] 人工逐个打开 DOI 对应页面，核对 DOI 确实指向该论文，并核对标题、作者顺序、年份和研究类型；不把 DOI 格式通过当成 DOI 真实存在。
- [ ] 按 DOI 去重；区分原始试验、二次分析、综述、评论及更正，不把它们当成独立试验重复计数。
- [ ] 人工核对原文方法与结果，确认样本、人群、随机分组、干预、对照、热量目标、随访时间和主要结局符合研究问题。
- [ ] 对每条关键发现核对原文或原表格：比较方向、单位、时间点、效应量、置信区间、P 值、分析人群及局限；注明可定位的段落、表格或补充材料。
- [ ] 无法取得原文时明确说明仅核对摘要；将原文人工核对记为未完成，相关未确认内容标注“未验证”，不声称已完成全文核实。
- [ ] 区分组内变化与组间差异；不把未达显著解释为证明无效或等效，不由短期效果推定长期效果。
- [ ] 检查综述与已收录试验的重叠，避免证据重复计数。

## 引用与编辑声明

- [ ] 核对支持／反驳／提及计数的来源与含义；拿不到写“未获取”，不填 0，不用总引用次数代替分类计数。
- [ ] 检查出版商、PubMed／PMC 或可用的编辑状态来源中的更正、撤稿和其他编辑声明；人工核对声明对应的原论文 DOI。
- [ ] 有更正时记录声明 DOI、日期、修改内容和来源，并核对是否影响研究结论。
- [ ] 未找到声明时保留检索范围与不确定性，不将“未发现”写成确定“无更正／无撤稿”。

## 全文获取与 GenAI 使用权

- [ ] 优先使用 @Article Galaxy；不可用时仅依据出版商或开放获取数据库核实获取状态，并记录依据与日期。
- [ ] 获取分类仅用“开放获取”“免费全文可获取”“订阅获取”“未核实”；不因页面可读就推断有开放再利用许可。
- [ ] GenAI 使用权单独判断，无法核实写“未核实”；不由开放获取、CC 许可或订阅访问自动推断专项使用权。
- [ ] 全程没有购买、租用、订购或授权任何文章，也没有为核查权限提交采购或授权请求。

## 数据、校验与页面验收

- [ ] 每篇包含标题、DOI、年份、作者、研究设计、关键发现、引用计数、编辑声明、证据来源及全文获取信息；缺失字段如实标注。
- [ ] 每篇有实际核实日期、具体证据来源说明及真实来源链接；全文获取信息有单独的依据、来源和核实日期。
- [ ] 执行 `node scripts/validate-review.js` 并通过；确认论文数量与本次筛选记录一致。--allow-empty 仅用于骨架检查，零篇不能作为研究完成。
- [ ] 执行 `node --check app.js` 并通过；使用 README 的本地 HTTP 服务打开页面。
- [ ] 人工核对页面研究问题、审阅日期、每类获取数量与 JSON 一致。
- [ ] 人工检查每篇文献的关键发现、引用计数、更正声明、来源链接、获取状态和 GenAI 使用权显示正确。
- [ ] 开关开启时仅剩开放获取／免费全文论文，两块区域同步；关闭后恢复全部，编号稳定，总体汇总不变。
- [ ] 检查空数组和无筛选结果时的空白提示，以及文件加载失败时的错误提示；不得显示虚构示例论文。
- [ ] 人工核对参考文献作者缩写、题名、年份与 DOI；现有结构缺少期刊名、卷期和页码，确认页面注明条目不完整，正式提交前据原文补齐。
- [ ] 检查桌面和窄屏阅读、键盘操作开关与链接，两块区域视觉区分清楚。
- [ ] 再次确认：脚本只能检查结构，DOI 真实性、原文证据和权限已经人工核查，未核查部分已如实标记。
